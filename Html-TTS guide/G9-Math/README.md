# ریاضی نهم — پلیر هر بخش و بستهٔ آمادهٔ TTS

- فایل HTML هر درس/مرور را مستقیم باز کنید؛ ابزارهای صفحه در خود فایل قرار دارند.
- هر بخش پلیر مستقل دارد. بخش بدون فایل صوتی تا زمان امبد، غیرفعال و مشخص است.
- متن هر بخش: پوشهٔ `tts/`؛ ورودی آمادهٔ تولید: پوشهٔ `arena-input/`.
- نام دقیق فایل‌های صوتی و اتصال‌ها: `audio-file-map.csv`.
- تولید و امبد مرحلهٔ بعد: `SECTION_AUDIO_TTS_GUIDE.fa.md`.
- نتیجهٔ بررسی: `SECTION_AUDIO_REPORT.fa.md` و `ryazif-section-audio-qc.json`.

صوت واقعی طبق درخواست شما بعداً تولید و امبد می‌شود. پسوند نام‌ها را تغییر ندهید؛ از ابزار `tools/embed_section_audio.py` برای اتصال فایل‌های واقعی استفاده کنید. هیچ فایل سکوتِ آزمایشی یا صوت فرضی در این بسته نیست.

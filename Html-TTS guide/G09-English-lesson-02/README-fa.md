# G09-English — صداگذاری درس ۲ کتاب اصلی

**وضعیت: checkpoint کاری؛ صوت ۱۵ بخش از ۴۰ بخش آماده است و جاسازی نهایی HTML هنوز انجام نشده است.**

درس `prospect3-lesson-02` با صدای مصوب آرتین (`voice-02`) و رها (`voice-05`) تولید می‌شود. منبع شامل ۴۰ بخش و ۲۵۲ نوبت ثبت‌شده است. شناسهٔ بخش‌ها، متن TTS، نام فایل‌های صوتی و مکث‌های ۷۰۰ میلی‌ثانیه‌ای، ۲ثانیه‌ای و ۸ثانیه‌ای حفظ می‌شوند.

## پیشرفت

- ۱۲ بخش با تطابق کامل `script_sha256` از صوت نهایی درس ۱ استفاده می‌کنند. این بخش‌ها هشت پی‌لود یکتا دارند و نام فایل ثبت‌شدهٔ درس ۲ را حفظ می‌کنند.
- دستهٔ ۰۰۲: ده کلیپ تازه تولید و پس از کنترل نرخ گفتار و سکوت پذیرفته شد؛ بخش‌های `goals`، `bridge-possession` و `continuous-negative` مونتاژ شدند.
- دو مکث هشت‌ثانیه‌ای `bridge-possession` با تلورانس ثبت‌شدهٔ فریم و مرز صوت تأیید شدند.
- برنامهٔ دستهٔ ۰۰۳ برای بخش‌های `start`، `context`، `pron-card-guide`، `reading`، `travel-words` و `examples` در `work/batch-003-generation-plan.json` ذخیره شده است.

## قالب خروجی و checkpoint

- خروجی بخش‌ها: WebM صوتی، Opus، تک‌کاناله، ۴۸kbps با پسوند `.weba`.
- برای جلوگیری از diffهای بزرگ و از دست رفتن کار بین نوبت‌ها، فایل‌های صوتی نهایی بخش‌ها و رسیدها در checkpointها روی برنچ ذخیره می‌شوند.
- جاسازی Base64 در HTML فقط پس از آماده‌شدن هر ۴۰ بخش انجام می‌شود. HTML فعلی هنوز خروجی نهایی نیست.
- کلیپ‌های موقت `work/clips` وارد Git نمی‌شوند.
- پس از ۴۰/۴۰، کنترل Base64، JavaScript، منابع، پلیرها و نبود autoplay انجام و سپس کامیت نهایی پوش خواهد شد.

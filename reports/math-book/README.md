API یا backend تازه ساخته نشده است. interface موجود در `MathHtmlWebView.kt` استفاده می‌شود:

```text

```

ذخیرهٔ کامل با `LocalStore("hamyar_math_html")` و کلید حساب‌محور `html:<kind>:<packId>` است؛ JSON با schema `hamyar-math-practice-1`، هر سند را در `documents[documentId]` مستقل نگه می‌دارد. فیلدهای قبلی حفظ می‌شوند؛ تلاش تازه، نتیجه، رسم و راهنمای قبلی را در تاریخچه نگه می‌دارد. هر خطا شامل شناسهٔ سؤال/هدف/آزمون/نشست، پایه، کتاب و کد، فصل واقعی، درس، مبحث، نوع، سطح، پاسخ دانش‌آموز و صحیح، زمان و دستهٔ احتمالی خطاست. در برگهٔ جامع، نمرهٔ جزئی و شیوهٔ خودارزیابی نیز ثبت می‌شوند.

`recordItem` به `StudyProgressRepository.recordExercise` و برای کارت به مسیر فعلی `reviewCardMath` متصل است. `recordExam` به `recordHtmlExam` و `MathExamLedger` وصل می‌شود؛ خطاهای شناسه‌دار بدون ازدست‌رفتن شمارهٔ سؤال ثبت می‌شوند. دفتر بومی درصد وزنی، شانزده سؤال اصلی، تعداد سؤال کاملاً درست و شناسهٔ خطاها را می‌گیرد؛ جزئیات بارم در JSON اپ باقی می‌ماند. ثبت چندفراخوانی این interface تراکنش سراسری جدیدی ندارد؛ API جدید برای آن اختراع نشده است.

در مرورگر مستقل، `localStorage` فقط fallback اعلام‌شده است و صفحه روشن می‌گوید ثبت در اپ فعال نیست. خطای ذخیره پنهان نمی‌شود. تست تغییر از fallback به حساب بومی تازه تأیید می‌کند پاسخ مرورگر به حساب دیگر منتقل نمی‌شود.

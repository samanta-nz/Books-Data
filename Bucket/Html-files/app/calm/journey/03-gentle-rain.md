## ۲) راهنمای تزریق صدا به HTML

1. در `03-gentle-rain.html` خطی را پیدا کن که با `const NAME=` شروع می‌شود؛ انتهای همان خط `AUDIO=[...]` هست و فعلاً ۶ رشته‌ی خالی دارد.
2. هر MP3 را base64 کن و به‌شکل data URI بگذار، به‌ترتیب بخش‌ها:
   ```js
   AUDIO=["data:audio/mpeg;base64,....","data:audio/mpeg;base64,...."]
   ```
3. تزریق خودکار (Python):
   ```python
   import base64, json, re, glob
   files = sorted(glob.glob('03-gentle-rain-*.mp3'))
   uris = ['data:audio/mpeg;base64,' + base64.b64encode(open(f,'rb').read()).decode() for f in files]
   h = open('03-gentle-rain.html', encoding='utf-8').read()
   h = re.sub(r'AUDIO=\[.*?\];', lambda m: 'AUDIO=' + json.dumps(uris) + ';', h, count=1, flags=re.S)
   open('03-gentle-rain.html', 'w', encoding='utf-8').write(h)
   ```
4. بعد از تزریق، پخش خودکار می‌شود: فایل بعدی بلافاصله بعد از قبلی شروع می‌شود، نوار پیشرفت کل تمرین را نشان می‌دهد و آخرین نقطه ذخیره می‌شود. اگر یکی از فایل‌ها خالی بماند، دکمه‌ها غیرفعال می‌مانند.
5. **تم:** صفحه خودکار تاریک/روشن می‌شود (prefers-color-scheme، با تغییر زنده) و دکمه ندارد. اگر وب‌ویوی اپ تم را به صفحه نمی‌رساند، از اپ بنویس: `webView.evaluateJavascript("setTheme('dark')", null)` (یا `'light'`، یا `setTheme()` برای برگشت به خودکار).

### بخش ۵: سپردن به باران

- **لحن این بخش:** آروم‌ترین و عمیق‌ترین بخش. کندتر بخون و مکث‌ها رو کامل رعایت کن. بدون هیچ فشار برای اینکه شنونده «باید» چیزی حس کنه. در بخش نوشتن روی شیشه، لحن بازی‌گوشانه و سبک باشه، نه جدی.
- برآورد: ۲۴۸ واژه + ۱۴۶ ثانیه مکث ≈ ۳:۴۳ دقیقه

حالا یه کار کوچیک می‌کنیم. اگه دوست ندارید، رد کنید و فقط به صدای بارون گوش بدید. هیچ اجباری نیست. **[مکث ۵ ثانیه]**

یه چیز کوچیک رو که امروز ذهنتون رو مشغول کرده انتخاب کنید. نه بزرگ‌ترین چیز. یه چیز کوچیک؛ شاید یه جمله، یه کار، یه حس. **[مکث ۸ ثانیه]**

حالا بلند شید و برید کنار پنجره. گوشه‌ی شیشه یه کم بخار نشسته. با یه انگشت، اون چیز رو روی بخار بنویسید. یه کلمه یا یه علامت. لازم نیست خوشخط باشه. **[مکث ۱۰ ثانیه]**

اگه ذهنتون گفت این کار یه کم بچه‌گونه‌ست، یه لبخند کوچیک بزنید و ادامه بدید. ذهن همینه، حرف می‌زنه. **[مکث ۸ ثانیه]**

نگاهش کنید. الان بیرون از سرِ شماست؛ روی شیشه‌ست. **[مکث ۸ ثانیه]**

و حالا فقط تماشا کنید. قطره‌ها آروم از بالای نوشته رد می‌شن. بخار کم‌کم دوباره می‌شینه. نوشته اول کم‌رنگ می‌شه، بعد محو، و آخرش فقط یه سایه‌ی خیلی نازک. **[مکث ۱۰ ثانیه]**

اون چیز از بین نرفته، فقط این لحظه جلوی چشمتون نیست. شاید بعداً دوباره بهش برگردید، با ذهنی که یه کم استراحت کرده. **[مکث ۸ ثانیه]**

اگه خواستید یه چیز دیگه هم بنویسید و بسپرید، می‌تونید. **[مکث ۱۲ ثانیه]**

اگه نه، برگردید سر جاتون، زیر پتو. **[مکث ۱۰ ثانیه]**

بدنتون چه حسی داره؟ نه اینکه چی فکر می‌کنید، چه حسی داره. شاید گرما، شاید سنگینی، شاید یه جور سبکی تو سینه. هر چی هست، درسته. **[مکث ۱۰ ثانیه]**

لازم نیست بزرگش کنید. لازم نیست نگهش دارید. فقط ببینید. **[مکث ۱۰ ثانیه]**

بذارید بارون بیاد، چراغ روشن بمونه، پتو گرم بمونه. **[مکث ۱۲ ثانیه]**

همین‌جور که هستید، خوبه. **[مکث ۱۵ ثانیه]**

### بخش ۶: برگشت و فرود

- **لحن این بخش:** به‌تدریج کمی روشن‌تر و پرانرژی‌تر شو، ولی هنوز نرم؛ مثل کسی که آروم بیدار می‌کنه. جمله‌های پایانی گرم و کوتاه باشن.
- برآورد: ۳۲۳ واژه + ۱۱۱ ثانیه مکث ≈ ۳:۳۱ دقیقه

کم‌کم وقتشه که از کنار پنجره برگردیم. ولی یه‌دفعه نه؛ مثل وقتی که از یه چرتِ راحت بیدار می‌شید، آروم و بی‌عجله. **[مکث ۵ ثانیه]**

یه نکته‌ی کوچیک برای بعد: لازم نیست هر دفعه بیست دقیقه وقت بذارید. تو روزهای شلوغ، همین‌قدر که چشم ببندید، سه تا نفس آروم بکشید و صدای بارون رو توی ذهنتون بیارید، دو دقیقه کافیه. مهم اینه که ذهن‌تون این مسیر رو یاد بگیره، تا هر بار راحت‌تر پیداش کنه. **[مکث ۵ ثانیه]**

### ۴-۶) تزریق تصویر پس‌زمینه به HTML

1. در `03-gentle-rain.html` خطی را پیدا کن که `const BG={light:"",dark:""};` است.
2. تصویرها را به data URI تبدیل و جایگذاری کن:
   ```python
   import base64, re
   def uri(p): return 'data:image/webp;base64,' + base64.b64encode(open(p,'rb').read()).decode()
   h = open('03-gentle-rain.html', encoding='utf-8').read()
   new = 'const BG={light:"' + uri('03-gentle-rain-bg-light.webp') + '",dark:"' + uri('03-gentle-rain-bg-dark.webp') + '"};'
   h = re.sub(r'const BG=\{.*?\};', lambda m: new, h, count=1, flags=re.S)
   open('03-gentle-rain.html', 'w', encoding='utf-8').write(h)
   ```
3. بعد از تزریق، تصویر با محو شدن نرم ظاهر می‌شود و انیمیشن ذرات (قطره‌های بارون + مه) روی آن اجرا می‌شود. با تغییر تم دستگاه، تصویر مناسب خودکار عوض می‌شود.

# Hamyar|code analyses — گزارش‌های نسخه‌دار

هر بستهٔ خروجی این نقش طبق [قاعدهٔ ثبت گزارش](https://github.com/samanta-nz/com.hamyareman.final/blob/main/Rules/REPORT_PUBLICATION_POLICY.md) پیش از پاسخ نهایی در پوشهٔ تاریخ UTC و شمارهٔ سه‌رقمی همان روز ثبت می‌شود. شمارهٔ بعدی از پوشه‌های موجود تعیین می‌شود؛ بستهٔ قدیمی بازنویسی نمی‌شود.

داخل هر بسته، گزارش خوانا، packet، ورودی متناظر، شواهد، manifest/hash و وضعیت آزمون‌های اجرا‌نشده قرار می‌گیرد. لینک گزارش نهایی باید به همان بسته اشاره کند. ثبت گزارش، مجوز merge، bucket sync، فعال‌سازی زنده یا release نیست.

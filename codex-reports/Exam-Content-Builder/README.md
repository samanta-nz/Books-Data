# محل ثبت نتایج Exam Content Builder

دستور مستقیم کاربر در تاریخ ۲۰۲۶-۱۰-۱۹: از این پس نتایج این نقش در [این پوشه](https://github.com/samanta-nz/Books-Data/tree/main/codex-reports/Exam-Content-Builder) ثبت و لینک آن در دستورهای ادامهٔ کار درج شود.

ساختار ثابت: `codex-reports/Exam-Content-Builder/YYYY-MM-DD/NNN-REFERENCE/`.

- تاریخ، تاریخ واقعی انتشار بسته با منطقهٔ زمانی صریح در metadata است؛ تاریخ ارجاع قدیمی را به‌جای تاریخ انتشار ننویس.
- شماره از `001` در هر روز آغاز می‌شود و پیش از انتشار با شاخهٔ دوردست تطبیق می‌یابد. پوشهٔ موجود بازنویسی نمی‌شود؛ اصلاح یا پاسخ بعدی در شمارهٔ بعد با ارجاع به بستهٔ قبلی ثبت می‌شود.
- `REFERENCE` شناسهٔ قابل پیگیری کار یا درخواست است. README هر بسته باید موضوع، نقش، شناسه و نسخهٔ درخواست‌ها، وضعیت، نسخه‌های محتوا/اپ و قدم بعد را مشخص کند.
- گزارش نتیجه، شواهد، پرامپت ادامه، packetهای واقعی و manifest فایل‌ها با اندازه و SHA-256 کنار هم ثبت شوند. packet قبلی برای جابه‌جایی مسیر تغییر داده نمی‌شود؛ لینک و hash اصلی معتبر می‌ماند.
- لینک پوشهٔ مادر و بستهٔ مشخص در تمام پرامپت‌های صادرشدهٔ این نقش درج شود. تحویل با لینک واقعی GitHub و commit انجام شود؛ مسیر محلی به‌تنهایی کافی نیست.
- گزارش‌های نقش‌های دیگر در مسیر تعیین‌شدهٔ خودشان باقی می‌مانند و اینجا به آن‌ها ارجاع داده می‌شود.
- انتشار گزارش روی `main` فقط فایل‌های این مسیر را شامل می‌شود و مجوز ادغام سورس، تغییر محتوا، sync باکت یا release نیست.
- وضعیت تألیف، QA، ارسال بین چت‌ها و انتشار جدا و مطابق شواهد ثبت شوند؛ snapshot قبلی یا تست مرورگر پذیرش مستقل یا اجرای گوشی نیست.
